# goit-pycore-hw-07

Тема 10. Домашня робота: «Розширене об'єктно-орієнтоване програмування в Python».

Консольний бот працює з `AddressBook`, об'єктами `Record`, полями `Name`,
`Phone` і `Birthday`. Підтримує кілька телефонів одного контакту,
день народження та список найближчих привітань.

## Файли

- [address_book.py](address_book.py) — усі класи адресної книги та розрахунок
  найближчих днів народження.
- [main.py](main.py) — декоратор `input_error`, обробники команд та цикл бота.

## Запуск

Потрібен Python 3.10 або новіший. Сторонніх залежностей немає.
Відкрийте термінал у папці проєкту та виконайте:

```bash
python main.py
```

У Linux/macOS за потреби використовуйте `python3 main.py`.

## Команди

| Команда | Дія |
| --- | --- |
| `hello` | Виводить `How can I help you?`. |
| `add name phone` | Створює контакт або додає ще один телефон до наявного. |
| `change name old_phone new_phone` | Замінює конкретний телефон контакту. |
| `phone name` | Показує всі телефони контакту. |
| `all` | Показує всі контакти, телефони та додані дні народження. |
| `add-birthday name DD.MM.YYYY` | Додає або оновлює день народження контакту. |
| `show-birthday name` | Показує збережену дату народження. |
| `birthdays` | Показує найближчі привітання, згруповані за датами. |
| `close` або `exit` | Виводить `Good bye!` і завершує роботу. |

Команди й пошук контактів не залежать від регістру. Ім'я зберігається
у тому написанні, у якому контакт створено. Ім'я в CLI має бути одним словом.
Повторний `add` дописує телефон до контакту. Номери зберігаються рядками,
тому початковий нуль не губиться. Контакт має не більше одного дня
народження; повторний `add-birthday` замінює попередню дату.

## Приклад діалогу

Вводьте команди по одній після запрошення `Enter a command:`.

```text
hello
add John 0501234567
add JOHN 0671234567
phone john
change John 0501234567 0931234567
add-birthday John 23.10.1995
show-birthday JOHN
all
birthdays
exit
```

Після двох команд `add` команда `phone john` поверне:

```text
0501234567; 0671234567
```

Після `change` у контакту залишаться `0931234567` та `0671234567`.
`show-birthday` поверне `23.10.1995`. Вміст відповіді на `birthdays`
залежить від поточної локальної дати комп'ютера.

## Валідація та обробка помилок

- Телефон має містити рівно 10 цифр від `0` до `9`. Знак `+`, пробіли,
  літери й неправильна довжина заборонені.
- Дата має точно відповідати `DD.MM.YYYY` і бути календарно правильною.
  Наприклад, `31.02.2000` і `1.1.2000` відхиляються. `29.02.2000` дозволено.
- `Birthday.value` зберігає об'єкт `datetime`; виведення використовує
  формат `DD.MM.YYYY`.
- Невідомий контакт, відсутній старий телефон, неправильні аргументи
  й некоректні дані обробляються через `@input_error`, бот продовжує працювати.
- Неправильний номер не створює порожнього контакту. Невдала зміна телефону
  або дня народження залишає попереднє значення незмінним.
- Порожнє введення й невідома команда повертають `Invalid command.`.
- `Ctrl+C` або завершення введення також коректно завершують програму.

## Найближчі дні народження

`AddressBook.get_upcoming_birthdays()` адаптовано з попередньої домашньої
роботи. Метод повертає список словників із ключами `name` та
`congratulation_date`; дата привітання має формат `YYYY.MM.DD`.

Правила розрахунку:

1. Беруться дні народження протягом семи календарних днів: сьогодні та
   наступні шість днів (`0 <= days_left < 7`).
2. Враховується перехід грудня в січень; день народження, що вже минув
   цього року, перевіряється в наступному році.
3. Якщо день народження припадає на суботу або неділю, привітання
   переноситься на найближчий понеділок. Через це дата привітання може
   опинитися за межами початкових семи днів.
4. Для народжених 29 лютого в невисокосному році використовується 28 лютого,
   після чого застосовується правило перенесення вихідних.
5. Контакти без дня народження пропускаються. Результат сортується за
   датою привітання. Команда `birthdays` групує імена за датами та показує
   дати у форматі `DD.MM.YYYY`.

Стан адресної книги зберігається в пам'яті лише протягом поточного запуску.
